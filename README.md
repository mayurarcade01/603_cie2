## Project Description
The **Product Catalog Management System** is a web application developed using ASP.NET Core MVC and .NET 8. It allows users to browse products, view product details, check prices and discounts, and select products.

## Technologies Used
- ASP.NET Core MVC
- C#
- .NET 8
- HTML and CSS
- Bootstrap
- JavaScript
- Web API integration

## Features
- Display a list of products.
- View product details, prices, and discounts.
- Save customer names using cookies.
- Store category preferences using session state.
- Cache product data in memory for better performance.
- Select products and display confirmation messages.
- Responsive user interface.

## How to Run the Project
1. Install the .NET 8 SDK and Visual Studio.
2. Extract the project ZIP file.
3. Open `603_cie2.csproj` in Visual Studio.
4. Restore the required NuGet packages.
5. Run the project using Visual Studio or execute `dotnet run` in the project directory.
6. Open the local URL displayed in the terminal or browser.

## Conclusion
This project demonstrates the use of ASP.NET Core MVC, Web API integration, cookies, session management, and in-memory caching to build a product catalog web application.
